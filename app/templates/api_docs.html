This API allows you to verify emails programmatically.

🔐 Your API Key

{{ user.api_key }}

📨 Endpoint

POST /api/verify

🧾 Parameters

  • api_key (string, required)
  • email (string, required)

📤 Example Request (cURL)

curl -X POST {{ url_for('api_verify', _external=True) }} \
     -d "api_key={{ user.api_key }}" \
     -d "email=test@example.com"
